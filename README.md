# English Daily (PWA)

Chạy thử trên máy:   python3 -m http.server 8000   → mở http://localhost:8000
Dùng trên mọi thiết bị: đưa cả thư mục lên hosting HTTPS miễn phí (Netlify Drop, GitHub Pages, Cloudflare Pages),
mở link trên máy/điện thoại → "Cài đặt ứng dụng" / "Thêm vào Màn hình chính".
Dữ liệu học lưu trong trình duyệt của từng thiết bị (Nhắc nhở → Cài đặt → Sao lưu/Khôi phục để chuyển máy).
